      #항목결과상태
      
          
        
      
      
      
    
      

    
    
      
      
      
        
      무작위로 만든 내 팀으로, 무작위로 행동하는 봇과 한 판을 둡니다. 상대 정보는 게임처럼 공개된 것만 보입니다.
      
        
      
          
          
        
      
      
      
      
      
        
      새 배틀을 누르면 양쪽 팀 6마리가 나오고, 선출 3마리와 선봉을 고르는 것부터 시작합니다.
