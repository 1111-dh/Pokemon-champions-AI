# 공식 공지 출처와 관리 규칙

포켓몬 챔피언스의 레귤레이션, 랭크배틀 시즌, 배틀 밸런스 조정은 **공식 공지가 기준**이다.
Showdown 엔진과 통계 사이트는 공지보다 늦게 반영되므로, 공지와 엔진이 다르면 공지를 따르고 차이를 [KNOWN_GAPS.md](KNOWN_GAPS.md)에 적는다.

## 확인 방법 (사용자가 직접 실행)

```
cd agent && uv run python -m pokechamp.data.official_news          # 확인하고 문서 갱신
cd agent && uv run python -m pokechamp.data.official_news --dry-run # 파일은 그대로 두고 결과만 출력
```

- 한 번 실행에 요청은 공지 목록 1건뿐이다.
- 결과는 [OFFICIAL_NEWS.md](OFFICIAL_NEWS.md)(사람이 읽는 목록)와 `official_news.json`(지난 확인 상태)에 저장한다. 둘 다 생성 파일이므로 직접 고치지 않는다.
- 새 공지는 🆕, 제목이나 게시 시각이 바뀐 공지는 🔄로 표시된다. 레귤레이션, 랭크배틀, 업데이트, 밸런스 조정처럼 엔진이나 데이터에 영향이 있을 수 있는 공지는 ⚠️로 표시된다.

## 관리 규칙

1. **언제 확인하나**: 작업 세션을 시작할 때, 단계를 시작할 때, `update-static`이나 `update-stats` 관련 작업 전, 그리고 레귤레이션이나 시즌 경계(매월 첫 수요일 전후, 레귤레이션 종료일) 직후. 스케줄러나 cron으로 자동 실행하지 않는다.
2. **⚠️ 공지가 새로 나오면** 본문을 읽고 다음을 처리한다.
   - 레귤레이션 공지: 기간, 참가 가능 포켓몬 링크, 새 메가, 규칙 변경을 [VERIFIED.md](VERIFIED.md)와 아래 대응표에 반영한다. 허용 목록 갱신이 필요하면 사용자에게 `update-static` 실행을 제안한다.
   - 밸런스 조정이나 업데이트 공지: 바뀐 기술, 특성, 도구를 [KNOWN_GAPS.md](KNOWN_GAPS.md)에 적고, 적용일 이후 Showdown 서브모듈이 반영했는지 확인한다.
   - 랭크배틀 시즌 공지: 대응표에 시즌을 추가한다.
3. 처리한 뒤 `OFFICIAL_NEWS.md`, `official_news.json`과 함께 문서 변경을 커밋한다(커밋 전에는 사용자에게 묻는다).

## 출처

게임 안 뉴스와 같은 내용이 포켓몬 HOME 뉴스 서버에 올라온다. 언어는 `ko`, `en`, `ja` 등이 있다.

| 용도 | 주소 | 형식 |
|---|---|---|
| 공지 목록 | `https://news.pokemon-home.com/{lang}/json/list.json` | JSON `{hash, data[]}`. 항목: `id`, `title`, `kindTxt`(레귤레이션/랭크배틀/점검 등), `infoKind`, `stAt`/`endAt`/`pubAt`(유닉스 초), `link`, `linkRom`(게임 코드). **챔피언스는 `linkRom`에 `"CHP"`** (SV, HOME, 레전즈 Z-A 공지도 섞여 있다) |
| 공지 본문 | `https://news.pokemon-home.com/{lang}/page/{id}.html` | HTML |
| 참가 가능 포켓몬 | 레귤레이션 공지 본문의 링크 `https://web-view.app.pokemonchampions.jp/battle/pages/events/{이벤트ID}/{lang}/pokemon.html` | HTML 안의 `const pokemons = [["0003-000", 1, "이상해꽃"], ...]` (전국도감번호-폼번호, 이름). 메가 폼은 들어 있지 않다 |
| 공식 사이트 | `https://www.pokemonchampions.jp/ja/news/`, `https://champions.pokemon.com/en-us/` | 홍보용. 레귤레이션 공지는 위 뉴스 서버가 더 자세하다 |

`infoKind` 값: 3 점검, 4 업데이트, 6 캠페인, 7 소식, 11 랭크배틀, 12 레귤레이션, 13 온라인 대회, 15 셀렉트, 16 배틀 패스, 18 오류. 목록의 `hash`가 바뀌면 새 공지가 있다는 뜻이다(`update-static`의 변경 감지에 쓸 수 있다).
