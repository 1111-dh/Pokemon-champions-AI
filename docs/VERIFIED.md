## 처리량 (단계 0 기준선)

측정 환경: Apple M3 (8코어), Node v24.22.3, 단일 프로세스. 무작위 봇끼리 대전시켰다(팀은 챔피언스 랜덤배틀 생성기로 만든 뒤 도구 중복을 고쳐 검증을 통과한 것).

| 항목 | 값 |
|---|---|
| 자체 대전 | 1,000판 / 오류 0 / 무한 진행 0 / 검증 실패 팀 0 |
| 판당 턴 수 | 중앙값 18, 최대 68 |
| 판 처리량 | **83.7판/초** (팀 생성과 검증 포함, 11.95초) |
| 턴 처리량 | **약 1,630턴/초** |
| 상태 복제(직렬화 + 복원) | 0.18ms + 0.21ms → **약 2,500회/초** (상태 JSON 약 38KB) |
| 메가진화 | 1,000판 중 639판에서 사용, 한 편이 두 번 이상 메가진화한 판 0건 |

**출처 시즌 표기를 믿지 않는다.** championsbattledata는 11-04 이후 데이터(공식 시즌 M-8)도 `M7` 폴더에 넣는다. 한카리아스 분포가 11-04에 급변하는 것(시즌 초기화)으로 확인했다. 그래서 시즌은 **데이터 날짜와 공식 시즌 달력**(공지에서 자동 생성)으로 판정하고, 출처 표기는 `page_season`에 그대로 남기며 불일치를 `verified=0`과 메모로 기록한다(`config/pokechamp.toml`의 `season_label_policy`로 strict 전환 가능).

**오래된 일괄 파일을 쓰지 않는다.** 같은 사이트의 `battle_data.zip`은 2026-06-26(레귤레이션 M-B)에 멈춰 있다(236종, 메가한카리아스Z 없음).

처리량: 처음 7일치 수집 약 6분, 새 데이터가 없으면 0.1초(색인의 최신 날짜만 확인). 새 날짜가 있을 때는 포켓몬 262마리에 요청 1번씩(요청 시작 간격 0.5초).
