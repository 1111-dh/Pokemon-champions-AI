# 계산기 탭 (데미지 · 스피드) 설계

## 의도
실전 탭은 에이전트에게 판단을 맡길 때 쓰고, 계산기는 **사용자가 직접 배틀할 때** 대면을 빠르게 확인하는 도구다.
배틀 중에 몇 번 눌러서 바로 답이 나오는 것이 가장 중요하다. 참고: 스마트누오(smartnuo.com).

## 목표
- 웹에 '계산기' 탭을 새로 둔다 (실전 탭 옆). 실전 탭과 연결하지 않는다.
- 내 포켓몬과 상대 포켓몬을 한 번 고르면 스피드 비교와 데미지 계산을 함께 본다.
- 데미지: 확정 n타, 난수 n타(확률)를 표시한다. 난수 때문에 확정으로 못 잡는 경우가 난수 n타다.
- 스피드: 실수치만 비교한다 (메가 체크 시 메가 폼 기준, 같으면 '동속').

## 하지 않는 것
- 스피드의 랭크·스카프·순풍 보정 (사용자 요청: 실수치만)
- 벽(리플렉터·빛의장막), n타 사이의 회복·잔여 데미지 — 화면에 한 줄로 알리고 `docs/KNOWN_GAPS.md`에 적는다
- 상대 세트를 분포로 다루기 (한 세트로 계산, 기본값은 통계 최빈 세트)

## 접근
- **선택: 웹 서버(Python)가 기존 엔진 API(`/damage`, `/stats`)를 부르고 n타 확률만 계산한다.**
- 버린 것: 브라우저에서 @smogon/calc를 직접 돌리기 (배틀 엔진과 계산이 어긋날 수 있다), 브라우저가 엔진을 직접 부르기 (지금 구조와 다르다).
- 기존 API를 최대한 쓴다: 포켓몬·도구·성격 목록은 `/api/builder/options`, 특성·기술·많이 쓰는 값은 `/api/builder/species`, 내 팀은 `/api/teams`·`/api/team/show`(sets), 선택 상자는 기존 picker.

## 화면
- 양쪽 카드(내 포켓몬 / 상대 포켓몬): 포켓몬, 성격, 도구, 특성, SP(H·A·B·C·D·S 한 줄, 옆에 실수치), 메가, 랭크(공·방·특공·특방), 상태이상, 현재 HP%.
- 내 쪽: '내 팀에서' 불러오기. 상대 쪽: 포켓몬을 고르면 통계 최빈 도구·특성·성격·SP로 채우고 '통계로 채움'을 표시 (바꿀 수 있다).
- 스피드 비교 한 줄이 위에, 데미지가 아래에. 데미지는 방향(내→상대 / 상대→내) 교체 버튼, 기술, 타수(연속기), 날씨, 필드, 급소.
- 결과: 데미지 범위(수치와 %), 판정('난수 2타 (62.5%) · 확정 3타' 또는 '확정 2타'), 급소 한 줄, 16단계 난수 펼쳐 보기.

## 계산
- `/damage`가 주는 16단계 난수(첫 타)를 매번 독립·균등으로 본다. 타수 k면 한 번 사용 = k개 난수의 합.
- n번 사용 합의 분포를 합성곱으로 구해 P(합 ≥ 방어측 현재 HP)를 계산한다.
- 확정 n타 = 최소 합으로도 쓰러지는 가장 작은 n. 난수 n타 = 0 < P < 1인 가장 작은 n (확정보다 작을 때만 표시).
- n은 최대 10까지 본다. 무효·변화기는 따로 표시한다.

## API
- `POST /api/calc/damage` {attacker, defender, move, hits, field, crit} → 엔진 `/damage` + n타 판정 (일반, 급소)
- `POST /api/calc/stats` {set, mega} → 엔진 `/stats` (실수치·스피드)

## 테스트
- n타 확률 순수 함수 단위 테스트 (확정, 난수 확률, 타수, 무효)
- 엔진이 떠 있을 때 API 통합 테스트

## 빌더에게 맡긴 것
- 타수 기본값(고정 연속기는 그 수, 2~5회는 2), 랭크 입력 형태, 카드 배치 세부
